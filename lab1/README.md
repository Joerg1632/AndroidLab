Навигация Сделать 3 различимых экрана (можно добавить разный текст или сделать разный цвет фона). На каждый экран добавить кнопку перехода на следующий экран. Пусть экраны называются А, B и C. Организовать навигацию следующим образом: 
1) Кнопка перехода на следующий экран открывает, собственно, следующий экран (A-> B-> C)
2) На экране А системная кнопка назад закрывает приложение, на остальных экранах переводит на предыдущий экран Должны получить такую схему: A <-> B <-> C-> A

Примечание: Фрагменты не используем, запуск активити сделать через activityLaunchMode. Перехват системной кнопки назад и завершение активити не будут засчитываться.

Сделать второй вариант с аналогичным набором функциональностей, но с использованием jetpack compose. Создать приложение с одним Activity, которое управляет навигацией между тремя Composable-экранами (A, B, C) с помощью Navigation Compose.

Для каждого из вариантов добавить логирование, чтобы по консоли логов можно было отслеживать происходящие в приложении события.
