# Currency Converter (Android)

Учебное Android-приложение — **конвертер валют**, реализованный с использованием **MVVM** и данных Центрального банка РФ.

## 📌 Описание

Приложение загружает актуальные курсы валют с сайта ЦБ РФ и позволяет конвертировать суммы между выбранными валютами. Поддерживается офлайн-режим, избранные валюты и тёмная тема.

Источник данных:  
https://www.cbr-xml-daily.ru/daily_json.js

---

## 🚀 Функциональность

- 📡 Загрузка списка валют и курсов с сайта ЦБ РФ
- 🔄 Конвертация между выбранными валютами
- 🔁 Своп валют (быстрая смена местами)
- ⭐ Экран **избранных валют** с возможностью добавления и удаления
- 📴 **Офлайн-режим** с уведомлением пользователя
- 🌙 Поддержка тёмной темы (Day/Night)
- ⚠️ Обработка ошибок и отображение сообщений пользователю
- 🪵 Логирование ключевых событий приложения
